# W3Schools "How To" Clone

Tugas mata kuliah Pemrograman Web: meniru tampilan https://www.w3schools.com/howto/default.asp hanya dengan HTML dan CSS.

## Anggota
| Peran | Nama | Bagian |
|---|---|---|
| Anggota A | _(isi nama)_ | Layout: top nav, sidebar, iklan, footer, responsive |
| Anggota B | Zaki Andriansa | 22 kartu demo iframe, Learn in Adventure Mode |

## Dokumen
1. [PLAN.md](PLAN.md): rencana lengkap, pembagian tugas, alur GitHub.
2. [CLAUDE.md](CLAUDE.md): konteks untuk Claude Code.

## Menjalankan
Buka `index.html` dengan ekstensi VS Code **Live Server**.

## Sumber Gambar
Semua foto dan avatar di `assets/img/demos/` (dipakai demo Slideshow, Login Form, Modal Image, Lightbox, Slideshow Gallery, Image Hover Overlay, Tab Image Gallery, Change Background on Scroll) adalah tangkapan layar gambar dari https://www.w3schools.com/howto/default.asp, hak cipta W3Schools (Refsnes Data). Dipakai hanya untuk keperluan tugas kuliah. Pixel-art Adventure Mode di `assets/img/adventure/` dibuat sendiri.
